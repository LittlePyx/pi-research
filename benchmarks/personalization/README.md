18 篇 arXiv 原始摘要于 2026-09-20 冻结，两个领域各 9 篇；每个问题使用本领域 9 篇和另一领域 3 篇对照，共 12 篇。题名、摘要、来源、版本、获取时间和内容摘要保存在 candidates.json。公开摘要由 freeze-personalization-candidates.py 获取，不使用 demo 的编写概述替代。已有快照不会被脚本覆盖。

四个问题分别涉及 KLS 界、随机局部化采样、有限码长失真、信息收缩。研究人物及明确/推断偏好由开发者编写，不是真实用户行为数据。文献来自已有 demo 涉及的方向，不是提示开发独立的留出测试集；它们构成探索性诊断集。

## 执行

在项目根目录使用 Node 24：

    npm run eval:personalization -- prepare
    npm run eval:personalization -- run --execute
    npm run eval:personalization -- report
    npm run eval:personalization -- score --judgments outputs/personalization-pilot-v1/blind-review.json

真实执行前将 DEEPSEEK_API_KEY 安全配置到运行进程的环境变量。不要把密钥写入命令参数、实验文件、Git 或聊天。脚本只向固定官方 DeepSeek 端点发送公开摘要和实验人物设定，不读生产数据库、浏览器 Cookie、用户 docs/、邮件或调度配置。

已有线上凭据时，使用受限服务端入口，不复制模型 Key。run-server-personalization-pilot.mjs 通过标准输入接收独立临时实验能力令牌（不是模型 Key），参数 --source-commit 为已核实部署提交。服务器只保存令牌 SHA-256，四小时过期，仅接收固定案例/分支/版本，拒绝任意提示词；新建独立 personalization_pilot_runs 表，对每个固定实验请求原子占位，最多 12 次模型调用，重复请求返回原记录，失败也不自动重跑。pending 状态需核对，不清占位强行二次调用。实验完成后关闭入口。此入口不读取用户研究空间、不更改模型配置、不启用邮件或任何定时任务。

输出默认在忽略跟踪的 outputs/personalization-pilot-v1。prepare 写入冻结实验、12 个实际请求体、独立盲审 JSON 与可阅读 HTML；不覆盖已填写的盲审文件。run 只执行真实模型调用，缺凭据直接报阻塞，不产生模拟排名。

每次调用保存后才继续下一次；失败停止，保留实际 token、耗时、状态及失败尝试，不把失败变为空排名。检查原因后可显式增加 --retry-failed；429 尊重 Retry-After。成功记录直接复用，不重新抽样挑选较好结果。进程锁避免同目录并发收费，异常硬终止留下的锁需确认进程已停止后处理。attempts.jsonl 为追加历史，runs.json 为最新投影；报告读历史可恢复中断时未写完的投影。部分损坏日志明确报错，不静默跳过。

更换输入/提示/源码版本应另选 --out-dir，不能混入同一实验。run 要求实验源文件已提交，记录完整提交版本；本轮计划 4×3=12 次调用，各最多 2200 输出 token、temperature=0、关闭思考，55 秒技术超时。实际输入长度随记忆条件不同，记录真实用量，不以字节数伪装 token。币种费用未获得账单或冻结价格表前保持 null。

## 隔离与解释

三组分别 none / explicit / all。复用生产 buildPreferenceGuidance，只改变记忆输入；同题候选顺序由固定散列确定，调用组次序轮换，提示/模型别名/输出预算相同。请求字段白名单排除 gain、known、facets、评审理由和评审者；无记忆分支也不接受来源种子、路线摘要或历史问答。明确掌握信息只从记忆传入，评估侧的 knownIds 不直送模型。

这是对共享偏好输入策略的固定候选排序探针。排序提示是新增实验提示，不是完整生产检索、深评和最终核验流水线；成功实验也不能直接声称生产推荐收益或端到端召回改善。模型要求精确摘要引文，服务端核对引用存在，但引用存在不证明解释正确。

盲审者在不知道三组排名的前提下，阅读相同完整人物需求，为每篇材料标 gain 0–3、研究方面 facets 和文字理由；已掌握可以仍然高度相关，不能为记忆组优势把它自动标为不相关。未判断保留 null。完成评审者身份、日期和独立性声明后才能评分；未完成或来源变更被拒绝。

报告保留逐篇三组名次、模型说明与原摘要引文，缺运行明确 unavailable；模型说明不是排名变化的因果证明。盲审完成前只报告实际排序和实验人物已知材料比例，不报告 P@5、nDCG 或提升百分比。单次、4 个编写问题只能发现个案，无法证明显著收益、普遍有效性或真实用户个性化效果。后续需要独立问题集、重复运行和多位领域审阅者。
